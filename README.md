# ｢Welcome to Elderfield｣ 日本語翻訳csv

｢[Welcome to Elderfield](https://store.steampowered.com/app/3195440/Welcome_to_Elderfield/)｣ の非公式日本語翻訳csvファイルです。

## 最も重要な注意事項

翻訳するにあたってネタバレを食らいたくなかったので，ツールを作成し翻訳しました．
ある程度は自分で確認しましたが，プレイ開始からクリアまで実際に問題なく動くかは”未確認”です．<br>
(危惧しているのはメッセージに含まれる内部変数名が翻訳に取り込まれて変更されてしまう事案．翻訳の良し悪しは機械翻訳なのでご愛敬ということで...)

## 最新版作成時のゲームバージョンと作成日

- Game Version: 1.0.0
- 2026/09/15

## ダウンロード

右側の「Releases」から最新版をダウンロードしてください。

## 導入方法

1. \SteamLibrary\steamapps\common\Welcome to Elderfield - Full Game の｢game_messages.csv｣を導入前に戻せるようにコピーし他の場所に保存しておきます．
2. Releasesから最新版のcsvファイルをダウンロードします。
3. ダウンロードした｢game_messages_jp_verx.x.x.csv｣の名称を｢game_messages.csv｣に変更します．
4. \SteamLibrary\steamapps\common\Welcome to Elderfield - Full Game にコピーし置き換えます．
5. ゲーム内のLanguageからJapaneseを選択します．

## アンインストール

バックアップした元の｢game_messages.csv｣に戻すか、Steamの｢ゲームファイルの整合性を確認｣を実行してください。
